## 확정 규칙 (6)

1. KMS+DB는 **한몸**. 내보내기만이 아니라 **입력 분류**도 KMS.
2. Studio는 **채널 종합**, blog-v2는 **사이트 블로그 전문** (이후 채널별 파생).
3. MD는 **단품 카드 + 패키지 듀얼**. 상품 SSOT는 MD, ops에 상품 마스터를 합치지 않음.
4. 사이트 배포 정본 = **GitHub Pages**. 제작·추가 코딩은 **기획 끝날 때까지 보류**.
5. 성장 3트랙(컨설턴트·MNC·레퍼럴)은 맵의 **훅 레이어** (백본 파이프를 대체하지 않음).
6. CRM·ops는 공개면 뒤의 **관계·예약 원장**. 지식핵·MD와 **ID로만** 연결.

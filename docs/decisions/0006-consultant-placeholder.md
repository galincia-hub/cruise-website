# ADR 0006 — 사이트 컨설턴트 노출

- Status: **accepted**
- Date: 2026-09-10
- Confirmed by: Kangsoo Hyun

## Context

성장 트랙에 Voyage Host/컨설턴트 네트워크가 있으나, 사이트 MVP에서 실명·실사진 노출 여부가 미정이었다. 제작은 기획 완료 전까지 보류.

## Decision

1. **플레이스홀더 노출:** 상담 담당/컨설턴트 **자리(카드·슬롯)는 둔다.**
2. **실명·실사진·개인 연락처는 넣지 않는다.** 더미 직함·이니셜·실루엣 수준만 허용.
3. CTA는 개인이 아니라 **카카오 채널**(ADR 0005)로 연결.
4. 실명 노출은 컨설턴트 네트워크·권한·초상권 준비가 된 뒤 별도 ADR로 승격.

## Consequences

- `_data/consultants.yml` 등은 스키마·슬롯만 유지하거나 플레이스홀더 항목.
- 3트랙 훅(컨설턴트 네트워크)과 UI 자리는 맞추되, 운영 데이터는 아직 비움.

## Still open

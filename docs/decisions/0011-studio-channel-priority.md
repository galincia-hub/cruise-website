# ADR 0011 — CruiseStudio 채널 우선순위

- Status: **accepted**
- Date: 2026-09-10
- Confirmed by: Kangsoo Hyun

## Context

CruiseStudio는 블로그·스레드·인스타·EDM 등 채널 소싱 종합 툴이다. blog-v2는 사이트 혼용 블로그 전문 정본이다. 제작 코딩은 기획 완료 전까지 보류이나, 채널 착수 순서는 잠근다.

## Decision

### 우선순위

1. **블로그 (blog-v2)** — 사이트 `_posts`·네이버 등. **지금 정본·최우선.**
2. **EDM** — 프로모·오퍼 안내 (MD 오퍼와 맞춤). 블로그 다음.
3. **스레드** — 짧은 배포·재유통.
4. **인스타** — 이미지·릴스형 소싱 (영상 원본 호스팅 없음, ADR 0001).

### 규칙

1. 새 채널은 **Studio 아래 전문 파생** (blog-v2 패턴). 사이트 레포에 콘텐츠 공장을 두지 않음.
2. **제작 재개 전·직후 우선 채널 = 블로그만.** EDM·스레드·인스타는 순번만 고정, 착수는 후순위.
3. 채널 산출물에서 추출한 사실은 **KMS 입력** (블로그 자동추출과 동일 원칙).
4. 공개 CTA·상품 링크는 사이트 게이트(카톡·가격 혼용 등)를 따른다.

## Consequences

- CruiseStudio README의 blog-v2 포인터와 일치.
- EDM/스레드/인스타용 레포·폴더는 해당 순위 착수 시 신설.

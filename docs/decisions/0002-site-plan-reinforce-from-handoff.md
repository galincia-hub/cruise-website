# 사이트 기획 플랜 — 보강안 (2026-09-10)

> Claude 인수인계서 v2 + HTML/CSS 프로토타입 4+5종을 **참고 라이브러리**로 대조한 결과.  
> 전부 수용하지 않음. PM=개발팀. 전략 전제: **범용 크루즈 백본** (싱가폴·알래스카 등 + 럭셔리), 이후 2트랙은 스킨.

관련: ADR 0001 미디어(accepted), `docs/README.md` 공유 허브.

## 유지 (이미 우리 플랜과 같음 — 그대로)

- 사이트 = 상담 유도 엔진 (예약몰 아님)
- CruiseMD → `_voyages`, CruiseStudio → `_posts` (브릿지는 Phase 3)
- ops / CRM 과 코드 미머지, ID 연동만
- 성장 모델 훅 3개만 Phase 4 (컨설턴트 / MNC / 리퍼럴)
- Human-in-the-loop (예약·금전·가격 확정)

| **럭셔리 전용 IA·카피 고정** (「Small Group Journeys only」 등) | 범용 전략과 충돌. 패턴만 남기고 카피는 재작성 |

# ADR 0010 — CRM 유입 (카톡 · 반자동 MVP)

- Status: **accepted**
- Date: 2026-09-10
- Confirmed by: Kangsoo Hyun

## Context

사이트 문의는 카톡만, 웹 폼 없음(ADR 0005). CRM 기본안과 고객 데이터는 로컬/private. 지식용 Supabase와 CRM용은 논리 분리(ADR 0009). 사용자가 **카톡에서 CRM으로의 반자동을 MVP에 포함**하기로 함. 제작·API 구현은 기획 문서화 후.

## Decision

### 유입

1. **손님 공개 입구 = 카카오 채널만.** 사이트 웹 폼·Formspree 없음.
2. **전화·방문 등**은 직원이 CRM에 수동 등록.
3. **MVP에 카톡 → CRM 반자동 포함.**

### 반자동 MVP 범위

**한다**

- 카톡 상담 중·직후, 리드/고객 필드를 **구조화해 CRM에 넣는 경로**를 MVP 범위로 둔다.
- 최소 필드 예: 이름(또는 호칭), 연락 채널(카톡), 관심 상품/항차(있으면 MD product_id 또는 sailing_code), 상담 요약, 유입=kakao, 일시.
- 구현 후보는 기획 잠금만: (a) 상담 템플릿 + 붙여넣기 파서, (b) 간단 내부 폼(직원 전용, 공개 사이트 아님), (c) 카톡 API/웹훅 연동. **어느 후보인지는 제작 착수 시 선택.**

**하지 않는다 (MVP 밖)**

- 손님용 사이트 문의 폼.
- 완전 무인 응대, 자동 견적 확정, 자동 예약.
- 고객 PII를 공개 깃/공개 Drive에 적재.

### 경계

| 시스템 | 역할 |
|--------|------|
| 사이트 | 카톡 CTA만 |
| CRM | 사람·리드·상담 이력 (private / Supabase CRM 쪽) |
| KMS/DB | 지식·사례 (상담 중 조회만, PII 저장소 아님) |
| MD | 상품·견적 산출 (리드와 ID 연결 가능) |
| ops | 예약·입금 (customer_id로 CRM 연결) |

## Consequences

- “폼 없음”은 **공개 사이트** 기준. **직원용 반자동 입력**은 CRM MVP에 포함.
- Supabase CRM 프로젝트/테이블은 후속. 지식 프로젝트와 분리.

## Still open

반자동 구현 후보 (a/b/c) 선택, Studio 채널 우선순위, 성장 3트랙 훅.

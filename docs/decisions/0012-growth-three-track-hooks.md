# ADR 0012 — 성장 3트랙 시스템 훅

- Status: **accepted**
- Date: 2026-09-10
- Confirmed by: Kangsoo Hyun

## Context

비즈니스 모델 3트랙은 사용자가 고정함: (1) 컨설턴트 네트워크 (2) MNC (3) 레퍼럴. 시스템 맵 v1에서 훅 레이어로만 취급. 사이트 게이트·CRM 유입과 맞춰 어디에 꽂을지를 잠근다. 사업 아이디어 확장은 하지 않음.

## Decision

### 트랙 to 훅

| 트랙 | 사이트 | CRM | ops | 권한 |
|------|--------|-----|-----|------|
| 1 컨설턴트 네트워크 | 플레이스홀더 (ADR 0006), 이후 실명 | 파트너/호스트, partner_type=consultant | 수수료·정산 코드 자리 | 파트너 등급 (이후) |
| 2 MNC | 캠페인 전용관 후순위 | MNC·캠페인, partner_type=mnc | MNC 지급 자리 | 이후 |
| 3 레퍼럴 | 추천 코드 UI 후순위 | 소개자·코드, partner_type=referral | 리워드/수수료 자리 | 이후 |

### MVP 범위

- **한다:** CRM/ops에 source / partner_type / partner_id(또는 동등) 필드 자리만 기획 확정. 사이트는 기존 게이트 준수.
- **안 한다 (MVP):** 레퍼럴 코드 공개 UI, MNC 전용관, 파트너 포털, 실정산 워크플로, 컨설턴트 실명 노출.

### 규칙

1. 3트랙은 MD-사이트·KMS 백본을 대체하지 않음 (맵 v1).
2. 명칭은 **MNC** (MC 아님). 복수 MNC 가능.
3. **레퍼럴은 컨설턴트가 아님** (계약·역할·노출 분리).
4. 공개면은 카톡·가격 혼용·컨설턴트 플레이스홀더를 따름.

## Consequences

- 제작 재개 시 스키마에 파트너 필드만 예약하면 됨. UI·정산은 후속 스프린트.

## Still open

파트너 수수료율·계약 세부(사업), 파트너 포털 일정. 1차 시스템 기획 묶음은 이 ADR로 닫을 수 있음.

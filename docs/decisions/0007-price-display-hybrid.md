# ADR 0007 — 사이트 가격 표시

- Status: **accepted**
- Date: 2026-09-10
- Confirmed by: Kangsoo Hyun

## Context

상품 가격을 사이트에 숫자로 노출할지, 상담 문의만 할지. GSA·비공개 요금과 대중 공개 요금이 혼재. 제작 코딩은 기획 완료 전까지 보류.

## Decision

1. **혼용 규칙**
   - **럭셔리 / GSA·비공개 요금 상품:** 시작가 숫자 없음. **상담 문의** (카톡 CTA, ADR 0005).
   - **대중·공개 가능 요금 상품:** **시작가 + 디스클레이머** (변동·인원·조건·포트택스 등 고지).
2. 데이터에 `price_display: inquiry | from_price` (또는 동등) 플래그를 전제로 한다. 구현은 제작 재개 시.
3. “부터” 가격은 확정 판매가가 아님을 UI에 명시.
4. 패키지(항공+지상) 듀얼도 **같은 혼용 원칙**. 세부는 MD 듀얼 기획에서.

## Consequences

- Phase 0 시드 방향과 맞음 (RSSC형 inquiry, 싱가폴 대중 from_price 후보).
- MD→사이트 브릿지가 `price_display`를 넘겨야 함.

# cruise-design.md — cruise-site 디자인 규칙
## Version 1.0 | 2026.04.07

> Claude Code는 cruise-site의 모든 HTML/CSS/Jekyll 템플릿 생성 시 이 문서의 규칙을 준수한다.
> 레퍼런스: Aman at Sea (절제감/톤), Abercrombie & Kent (구조/기능/정보밀도)

## 1. 색상 체계

### 1-1. 기본 팔레트 (미확정 — 두 옵션 중 선택 대기)

**Option A: Navy + Orange (기존 v2)**
```
--primary:       #1B365D    /* 네이비 */
--accent:        #E87C3E    /* 오렌지 */
--accent-hover:  #D06A2E    /* 오렌지 다크 */
```

**Option B: Deep Navy + Gold (신규 제안)**
```
--primary:       #1B2A4A    /* 딥 네이비 */
--accent:        #C4A265    /* 골드 */
--accent-hover:  #B08E50    /* 골드 다크 */
```

### 1-2. 공통 색상 (옵션 무관)
```
--bg-white:      #FFFFFF
--bg-warm:       #F5F0EB    /* 웜 베이지 — 아만/A&K 참고 */
--bg-section:    #FAF8F5    /* 섹션 구분용 연한 배경 */
--text-primary:  #1A1A1A    /* 본문 */
--text-secondary:#666666    /* 보조 텍스트 */
--text-caption:  #999999    /* 캡션/메타 */
--line-light:    #E5E0DB    /* 구분선 — 아만 참고, 회색 아닌 웜톤 */
--line-medium:   #D0C8BE    /* 테이블/카드 보더 */
--status-offer:  #C0392B    /* OFFER/프로모션 빨간 글씨 — A&K 참고 */
--status-avail:  #27AE60    /* 예약가능 초록 */
--status-limited:#E67E22    /* 한정예약 주황 */
--status-call:   #7F8C8D    /* 전화문의 회색 */
```

### 1-3. 색상 운용 원칙
- 배경은 --bg-white 또는 --bg-warm 교차 사용으로 섹션 구분
- 포인트 컬러는 절제적으로 사용: CTA 버튼, 선택된 탭 언더라인, OFFER 텍스트에만
- 구분선은 순수 회색(#ccc) 금지 → 웜톤 라인 컬러 사용
- 이미지 색감은 사이트 톤과 통일 (웜톤 기반 — 차가운 블루 톤 이미지 지양)

## 2. 타이포그래피

### 2-1. 폰트 스택
```
--font-heading:  'Noto Serif KR', Georgia, serif;       /* 제목 — 품격 */
--font-body:     'Noto Sans KR', 'Apple SD Gothic Neo', sans-serif; /* 본문 — 가독성 */
--font-ui:       'Noto Sans KR', sans-serif;             /* UI 요소 — 깔끔 */
--font-accent:   'Cormorant Garamond', serif;            /* 영문 장식용 — 럭셔리 톤 */
```

### 2-2. 크기 체계 (px 기준, rem 변환 적용)
```
--text-hero:     48px / 1.2   /* 히어로 제목 */
--text-h1:       36px / 1.3   /* 페이지 제목 */
--text-h2:       28px / 1.35  /* 섹션 제목 */
--text-h3:       22px / 1.4   /* 서브 제목 */
--text-body:     16px / 1.7   /* 본문 — 한국어 가독성 기준 */
--text-small:    14px / 1.6   /* 보조 텍스트 */
--text-caption:  13px / 1.5   /* 캡션/메타 */
--text-ui:       14px / 1.4   /* 버튼/네비/배지 */
```

### 2-3. 타이포 원칙
- 제목: Serif(Noto Serif KR), 본문: Sans-serif(Noto Sans KR) — 혼용 금지
- 영문 선사명/상품명은 --font-accent 허용 (예: "Seven Seas Splendor")
- 볼드 남용 금지 — 제목과 강조 라벨에만 사용
- 라인 색상과 굵기까지 섬세하게 조절 (A&K 참고)
- letter-spacing: 제목에 0.02em, 캡션에 0.05em, 영문 대문자 라벨에 0.1em

## 3. 간격 & 여백 시스템

### 3-1. 기본 단위 (8px 그리드)
```
--space-xs:   4px
--space-sm:   8px
--space-md:   16px
--space-lg:   24px
--space-xl:   32px
--space-2xl:  48px
--space-3xl:  64px
--space-4xl:  96px
--space-section: 80px  /* 섹션 간 간격 */
```

### 3-2. 여백 원칙
- 컨테이너 최대 너비: 1280px, 좌우 패딩 40px (모바일 20px)
- 섹션 간 간격: --space-section (80px) — 아만의 여유 있는 호흡 참고
- 카드 간 간격: --space-lg (24px)
- 텍스트 블록 내부: --space-md (16px)
- 여백은 넉넉하게 — 럭셔리 = 공간의 여유

## 4. UI 컴포넌트 패턴

### 4-1. 스티키 서브 네비게이션 (필수)
- 상품 상세 페이지에서 스크롤 시 상단 고정
- 탭: Overview | Itinerary | Ship | Dates & Prices | Details
- 현재 활성 섹션: accent 컬러 언더라인 (2px)
- 배경: rgba(255,255,255,0.95) 반투명 + 하단 1px 라인
- z-index 상위 배치

### 4-2. 탭 레이어 전환
- 같은 콘텐츠의 다른 옵션을 페이지 이동 없이 전환
- 적용: 스위트 등급별 비교, 같은 목적지 다른 선사 비교
- 선택된 탭: 솔리드 배경(--primary), 비선택: 아웃라인
- 전환 시 부드러운 fade (0.2s ease)

### 4-3. 모달 팝업 (레이어)
- 적용: 기항지 관광 정보, 객실 상세 (Photos/Floor Plan/Deck Plan)
- 구조: 좌측 이미지 캐러셀 + 우측 텍스트 정보
- 상단 탭으로 뷰 전환 (선택된 탭: 솔리드 배경)
- 닫기: 우상단 × 버튼 + 배경 클릭
- 공통 컴포넌트로 제작 → 데이터만 바꿔서 모든 객실/기항지에 재사용

### 4-4. 날짜 선택 버튼
- 같은 항차의 다른 출발일을 버튼 전환으로 비교
- 선택된 날짜: 솔리드(--primary 또는 검정), 비선택: 아웃라인(흰색)
- 페이지 이동 없이 가격/상태 즉시 변경

### 4-5. 가격 테이블 + 상태 배지
- 행 단위 구성: 객실타입 | 가격 | 상태배지 | 드롭다운 화살표
- 상태 배지: AVAILABLE(초록) / LIMITED AVAILABILITY(주황) / CALL FOR AVAILABILITY(회색)
- 드롭다운 펼침: 객실 이미지 + 카테고리 + 설명 + 가격 + 싱글서플 + 캐빈/발코니 면적
- OFFER 표시: --status-offer 빨간 글씨
- 하단 고정 바: "10박 | from ₩XX,XXX,XXX | 상담 문의" (A&K 패턴)

### 4-6. CTA 버튼
- Primary: 솔리드 배경(--primary) + 흰 텍스트
- Secondary: 아웃라인(1px --primary) + --primary 텍스트
- 우상단 듀얼 CTA: "항해 플래너"(아웃라인) + "전화 상담"(솔리드)
- 한국 시장: 전화(02-775-0100) + 카카오톡 CTA 필수 — "Request a Quote" 폼 방식 지양

### 4-7. 카드 컴포넌트
- 그림자: box-shadow: 0 2px 8px rgba(0,0,0,0.06)
- 모서리: border-radius: 4px (둥글지 않게, 절제감)
- 호버: 0.3s ease, 그림자 깊어짐 + 살짝 위로 translate(-2px)
- 이미지: 상단, 비율 3:2 고정, object-fit: cover
- 카테고리 배지: 좌상단 오버레이 (반투명 배경 + 흰 텍스트)
- OFFER 배지: 빨간 배경 + 흰 텍스트 (카테고리 배지 옆)

### 4-8. Enquiry Form (상품별 문의)
- 모달 팝업으로 구현
- 좌측: 해당 상품 이미지 + 상품명 + 카테고리 + 일수 + 정원 + 가격 (자동 매칭)
- 우측: 전화번호 표시 + 문의 폼 (이름/전화/이메일/메시지)
- 공통 컴포넌트로 제작 → 상품 정보만 동적 매칭
- 한국판 추가: 카카오톡 상담 버튼

### 4-9. 필터링 시스템
- 좌측 사이드바 또는 상단 바에 다층 필터
- 필터 카테고리: 선사 / 지역 / 출발월 / 기간(Duration) / 여행스타일
- 선택된 필터: 상단에 태그 표시 (× 제거 가능)
- 필터 로직: 그룹 내 OR / 그룹 간 AND
- 결과 수 실시간 표시
- Duration 구간: 1-7박 / 8-14박 / 15-21박 / 22박+

### 4-10. 관련 콘텐츠 추천
- 상품 페이지 하단: 같은 카테고리 추천 상품 캐러셀 (3-4개)
- 카테고리 드롭다운으로 하위 카테고리 전환 가능
- 블로그 글 하단: 관련 글 3개 + 관련 상품 3개 (양방향 연결)

## 5. 이미지 가이드라인

### 5-1. 이미지 소싱 구조
- 이미지DB: cruise-site/assets/images/ 하위 선사별 폴더
  - regent/, silversea/, crystal/, oceania/, ritzcarlton/, fourseasons/
  - common/ (기항지, 일반 크루즈 이미지)
- 파일명 규칙: {선사}_{선박}_{카테고리}_{번호}.jpg
  - 예: regent_splendor_suite-deluxe_01.jpg
- 선사별 공홈 이미지 → 해당 선사 상품에만 자동 매칭
- 이미지 base URL을 _config.yml 변수로 관리 (나중에 CDN 이관 대비)

### 5-2. 이미지 스타일
- 색온도: 웜톤 기반 (사이트 전체 톤과 통일)
- 채도: 자연스럽게, 과포화 금지
- 히어로: 풀 너비, 최소 높이 500px, 텍스트 오버레이 시 그라데이션 처리
- 카드: 3:2 비율, object-fit: cover
- 모달: 캐러셀, 좌우 화살표, 도트 인디케이터

### 5-3. 이미지 리터치 기준
- 밝기: 사이트 배경(--bg-warm)과 조화되는 수준
- 필터: 약간의 웜톤 오버레이 (차가운 블루 톤 보정)
- 대비: 중간 — 너무 강하지 않게

## 6. 페이지별 구조 명세

### 6-1. 홈페이지
```
[히어로] 풀스크린 이미지 + 상품명/CTA 오버레이
[선사 소개] 6개 선사 로고/이미지 + 간략 설명 → 선사 페이지 링크
[추천 상품] 3열 카드 그리드 (필터: 에디터 추천 / 프로모션 / 2명 추가 시 출발)
[블로그 미리보기] 최신 글 3개 + "더보기" 링크
[회사 소개 요약] 24년 전문성 + SB7 원라이너
[CTA] 전화/카카오톡 문의
[푸터] 회사 정보 + 선사 링크 + 소셜 + 뉴스레터 구독
```

### 6-2. 선사 페이지 (리젠트 = 템플릿)
```
[히어로] 선사 대표 이미지 + 선사명
[선사 소개] 텍스트 + 이미지 좌우 교차 배치 (아만 패턴)
[선박 목록] 카드 그리드 + 이미지 캐러셀 + 드롭다운 스펙
[객실 가이드] 등급별 카드 → 클릭 시 3탭 모달 (Photos/Floor Plan/Deck Plan)
[다이닝] 레스토랑별 카드 + 모달 상세
[BDM 인터뷰] 선사 담당자 프로필/인용구/미팅 사진 (기존 v2)
[추천 항차] 해당 선사 상품 3개
[관련 블로그] 해당 선사 태그 글 3개
```

### 6-3. 상품 상세 페이지
```
[히어로] 목적지 이미지 + 상품명 + 박수/항구수 + 카테고리 배지
  → 이미지DB 키워드 매칭 자동 배치
  → 메타데이터(상품명/카테고리/박수) 내부 지정값 자동 노출
[스티키 네비] Overview | Itinerary | Ship | Dates & Prices | Details
[Overview] 상품 설명 + 이미지 좌우 교차 (선사별 이미지DB 자동 매칭)
[Itinerary] 일정표 + 지도 + 기항지 카드 (클릭 → 모달 팝업)
[Ship] 선박 이미지 캐러셀 + 드롭다운 스펙 (CruiseDB 데이터)
[Dates & Prices]
  - 좌: 포함사항 (아이콘 + 텍스트 리스트)
  - 우: 날짜 선택 버튼(검정=현재/흰색=다른날짜) + 객실별 가격 테이블
  - 드롭다운: 객실 이미지 + 상세 정보
  - 객실 이미지 네모 아이콘 → 3탭 모달 (공통 컴포넌트)
  - DECKPLAN 버튼 → 새창 (별도 덱플랜 페이지, 통일 구조)
  - 상태 배지: AVAILABLE / LIMITED / CALL
  - 하단 고정 바: 박수 | 시작가 | "상담 문의" CTA
[Details] 필수 정보 + 유의사항
[Enquiry Form] 상품 자동 매칭 문의 모달 (공통 컴포넌트)
[추천 상품] 같은 카테고리 3개 캐러셀 + 카테고리 드롭다운 전환
[관련 블로그] 같은 선사/지역 글 3개
```

### 6-4. 블로그 메인
```
[히어로] 대표 이미지 (실제 사진)
[카테고리 탭] 전체 | 선박리뷰 | 객실가이드 | 다이닝 | 기항지가이드 | 선사비교 | 크루즈입문 | 프로모션
[필터] 선사 6개 + 지역 9개 칩 (멀티셀렉트, 그룹 내 OR / 그룹 간 AND)
[피처드 포스트] 1개 대형 카드
[카드 그리드] 3열, 페이지네이션
```

### 6-5. 블로그 개별 글
```
[카테고리 탭 바] (검색/필터 없이 탭만)
[헤더 배지] 카테고리 + 선사 + 지역
[본문]
[관련 글] 같은 선사·지역 3개 (스마트 매칭)
[관련 상품] 3개 카드
```

### 6-6. 회사 소개
```
[히어로] 회사 이미지/팀 사진
[브랜드 스토리] 24년 전문 역사 (SB7 구조)
  1) 창립 스토리 — 모두투어 그룹 내 크루즈 전문 부서로 시작
  2) 전문성 축적 — 리젠트 GSA, 6개 선사 공식 총판
  3) 고객 철학 — "꿈의 항해를 설계하는 파트너"
  4) 신뢰 강화 — 실적, 수상, 고객 후기
[팀 소개] 담당자별 프로필
[파트너 선사] 로고 + 간략 설명
[CTA] 전화/카카오톡 문의
```

### 6-7. Offers (프로모션)
```
[히어로] 프로모션 대표 이미지
[프로모션 카드] 이미지 + 할인 정보 + VIEW DETAILS → Enquiry Form 연동
[프로모션 유형: 프로모션 / 모객집중 / 담당자추천 / "2명 추가 시 출발확정"]
```

## 7. 데이터 연동 구조

### 7-1. 이미지 매칭
- 히어로/오버뷰 이미지: 상품 YAML frontmatter의 image 키워드 → 이미지DB 검색
- 선사 이미지: cruiseline 태그 → 해당 선사 폴더에서 자동 매칭
- 기항지 이미지: destination 태그 → destinations/ 폴더 매칭
- _config.yml에 image_base_url 변수 관리 (CDN 이관 대비)

### 7-2. 상품 데이터
- CruiseMD → sailings_index.json → Jekyll _data/ 또는 _voyages/ 마크다운
- 필수 필드: 선사/선박/항로/출발일/박수/가격대/포함서비스/카테고리/상태
- 구조화 필터 필드: region/duration/month/year/travel_style
- 모객 상태 필드: passengers_needed/passengers_confirmed/departure_status
- JSON-LD 스키마: Product/Offer 자동 생성

### 7-3. 공통 컴포넌트 목록
Jekyll _includes/로 관리, 데이터만 바꿔서 재사용:
- ship-card.html — 선박 카드

- price-table.html — 날짜/가격/상태 테이블
- product-card.html — 상품 카드
- blog-card.html — 블로그 카드

## 9. 반응형 브레이크포인트

```
--bp-mobile:     480px
--bp-tablet:     768px

--bp-wide:       1280px
```

### 반응형 원칙
- 모바일 퍼스트 설계, PC에서 확장
- 3열 → 2열(태블릿) → 1열(모바일)
- 스티키 네비: 모바일에서 햄버거 메뉴 또는 가로 스크롤 탭
- 모달: 모바일에서 풀스크린
- 가격 테이블: 모바일에서 카드형으로 전환
- 터치 타겟: 최소 44px × 44px

## 10. 성능 가이드라인

- 이미지: WebP 우선, JPEG 폴백, 최대 200KB/장

- 나머지 이미지: loading="lazy"
- 폰트: Noto Sans KR/Noto Serif KR — subset 한국어 + 라틴

- Jekyll 빌드 최적화: includes 캐싱, 불필요한 플러그인 제거

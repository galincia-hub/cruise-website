# docs/ — 공유 작업 허브 (Claude ↔ 개발팀)

이 폴더는 **채팅 첨부 대신** Claude와 개발팀(Grok)이 같은 산출물을 주고받기 위한 공간이다.

## 시작점

- **[전체 맵 v1 (확정)](overview/system-map-v1.md)** — 구성·인과·확정 규칙 6
- **[크루즈AI시스템 개요](overview/cruise-ai-system.md)** — 역할·흐름 상세

## 규약

| 경로 | 용도 |
|------|------|
| `docs/overview/` | 시스템 전체 개요·**확정 맵** |
| `docs/handoff/` | 인수인계·세션 요약 (민감 전략 전문은 private 유지 가능) |
| `docs/decisions/` | 확정된 기술·운영 결정 (ADRs) |
| `docs/library/` | 재사용 프로토타입·토큰 등 **참고 라이브러리** (지침 전부 준수 대상 아님) |

- **원본 SSOT는 Git.** Obsidian은 미러·열람용으로만 써도 된다.
- 사이트 코드는 레포 루트 Jekyll 구조. `docs/`는 빌드 exclude 유지.
- 이미지·영상 바이너리는 여기 넣지 않는다. URL만 문서에 적는다.
- 고객데이터·자격증명·재무 문서는 공개 레포에 넣지 않는다.
- **코딩·제작은 기획 완료 전까지 보류** (맵 v1 기준).

## 현재 전략 (2026-09)

- 목표는 **범용 크루즈 백본** (싱가폴·알래스카 등 + 럭셔리). 과거 럭셔리 전용 시안은 라이브러리.
- 나중에 럭셔리 2트랙이 되어도 **스킨 교체**, 백본·ERP 연동 유지.
- Claude/과거 산출물은 **선택적 참고**. PM은 개발팀, 우선은 사용자와 상의.
- 지식층(CruiseKMS+CruiseDB)이 상담 차별화 자산의 핵. 상세는 개요·맵 문서.
